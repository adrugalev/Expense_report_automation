## Реальные пользовательские сценарии

Общий сценарий:

1. Пользователь выбирает один из трех типов отчета.
2. Выбирает инициатора из `data/employees.json`.
3. Загружает PDF/JPG/PNG чеки.
4. Приложение извлекает текстовый слой, QR и/или OCR, затем показывает редактируемую таблицу.
5. Пользователь проверяет дату, продавца, адрес, ИНН, сумму и фискальные реквизиты.
6. Заполняет поля выбранного сценария.
7. Генератор создает DOCX и предлагает отдельные файлы или ZIP.

Командировка:

- город, цель, даты начала и окончания;
- даты формы по умолчанию берутся из чеков;
- маршрут такси и текст компенсации формируются автоматически;
- создается служебная записка из активного DOCX-шаблона.

Представительские расходы:

- дата мероприятия, место, кафе, контрагент, цель, результат и участники;
- место, кафе и дата подставляются из распознанного чека;
- пустые деловые поля получают детерминированное автозаполнение;
- доступны общий комплект, отдельный комплект на чек и отдельные контрагенты на чек;
- документ строится программно через `python-docx`.

Подарки:

- дата покупки подставляется из чека;
- пользователь редактирует цель расходов;
- название, количество, получатели и часть служебных значений сейчас задаются автоматически;
- документ строится программно через `python-docx`.

## Слои и зависимости

```text
Streamlit app.py
  -> EmployeeDirectory -> Employee + approval rules
  -> receipt_parser -> QR / PDF text / Tesseract / RapidOCR / address lookup
  -> Pydantic report models
  -> report builders -> formatters + templates + python-docx/docxtpl
  -> filesystem output
```

Независимы от Streamlit и пригодны для прямого переиспользования:

- `src.models`;
- `src.receipt_parser` и `src.address_lookup`;
- `src.report_builders`;
- `src.docx_generator` и `src.template_manager`;
- `src.formatters`, `src.validators`, `src.approval`, `src.phone`;
- большая часть `src.employee_directory`.

## Связность и дублирование

- В `app.py` смешаны UI, состояние, загрузки, кэш распознавания и запуск генераторов.
- Справочник профилей для автозаполнения представительских расходов находится в UI-файле.
- Сборка отдельных комплектов по каждому чеку находится в `app.py`, хотя это бизнес-операция.
- ZIP в памяти в `app.py` дублирует файловый ZIP из `src.archive`.
- Проверка дат и сумм частично дублируется между Pydantic-моделями и `src.validators`.
- Метаданные типов отчетов повторяются между `app.py` и `TemplateManager`.
- README описывает загрузку шаблонов и редактирование сотрудников, которых в текущем UI уже нет.

## Текущее хранение

- сотрудники: изменяемый JSON-файл, без блокировки и транзакций;
- шаблоны: DOCX в файловой системе;
- загруженные чеки: временный файл, удаляемый после разбора;
- результаты: общая папка `output/` с уникализацией имени;
- состояние формы и результат скачивания: только Streamlit session state;
- история, пользователи и черновики: отсутствуют.

## Ограничения и риски миграции

- Runtime-установка OCR меняет Python-окружение и удаляет OpenCV-пакеты во время работы приложения. В production OCR должен устанавливаться при сборке образа.
- Nominatim вызывается синхронно, без серверного rate limit и долговременного кэша.
- Legacy upload не проверяет реальный MIME, сигнатуру и размер файла.
- JSON-справочник не рассчитан на конкурентную запись несколькими пользователями.
- Файлы разных пользователей попадают в одну папку и не имеют metadata/history.
- Парсер использует `1.00` как заметное пользователю значение при нераспознанной сумме.
- Представительские и подарочные документы не используют хранящиеся рядом дополнительные шаблоны; активен один итоговый документ на сценарий.
- Авторизация отсутствует, поэтому прямое размещение legacy Streamlit в интернете небезопасно.
- Базовые тесты: 92 passed, 8 skipped; один тест версии падал из-за устаревшей даты `06.08.2026`.

## Решение для миграции

Существующий `src/` уже является подходящим shared core. Создавать искусственный `shared/` не требуется. Новые FastAPI services будут вызывать `src` напрямую, а orchestration, которое сейчас живет в `app.py`, будет вынесено в независимые функции с сохранением legacy-оберток.

Legacy entrypoints `app.py` и `streamlit_app.py`, каталог шаблонов, тестовые данные и прежняя команда запуска остаются на месте.
